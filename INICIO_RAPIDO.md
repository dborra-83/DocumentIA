## 🔧 Si Algo No Funciona

### History no carga
1. Refrescar la página (F5)
2. Verificar que estás logueado
3. Abrir consola del navegador (F12) para ver errores

### Documento no aparece después de subir
1. Esperar 15-20 segundos
2. Refrescar la página
3. El documento se procesa en background

### Servidor no responde

npm run dev
